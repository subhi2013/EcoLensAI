🌱 EcoLens — Waste Observation and Analysis

About

EcoLens is a Python project that records waste observations and analyzes waste categories to encourage better waste management.

Features

Add and validate waste observations

Search for waste items

Count and rank waste categories

Calculate category percentages

Identify the most common waste category

Generate eco-friendly suggestions

Save and load observations using JSON

Handle missing or invalid saved data

Technologies Used

Python

JSON

Dictionaries, lists, loops, and functions

Goal

To use programming and data analysis to encourage environmentally responsible habits.

How to Run

Run the Python file using Python 3. Make sure the project folder is writable so saved observations can be stored.
